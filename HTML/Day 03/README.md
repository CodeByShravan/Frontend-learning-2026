📚 1. What is an HTML List?

An HTML list is used to display related items in an organized format.

There are three main types of HTML lists:

1. Unordered List
2. Ordered List
3. Description List

🔹 2. Unordered List — "<ul>"

An unordered list displays items using bullets.

Example:

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

🔹 3. Ordered List — "<ol>"

An ordered list displays items in a sequence, usually with numbers.

Example:

<ol>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
    <li>Learn JavaScript</li>
</ol>

🔹 4. List Item — "<li>"

The "<li>" tag represents an individual item inside an ordered or unordered list.

🔹 5. Nested Lists

A nested list is a list inside another list.

Example:

<ul>
    <li>Frontend Development
        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>
    </li>
</ul>

🔹 6. Description List

A description list is used to display terms and their descriptions.

- "<dl>" — Description list
- "<dt>" — Term
- "<dd>" — Description

Example:

<dl>
    <dt>HTML</dt>
    <dd>Defines webpage structure.</dd>

    <dt>CSS</dt>
    <dd>Styles the webpage.</dd>
</dl>

📊 7. What is an HTML Table?

An HTML table displays structured data in rows and columns.

Important tags:

- "<table>" — Creates a table.
- "<caption>" — Adds a table title.
- "<tr>" — Creates a table row.
- "<th>" — Defines a header cell.
- "<td>" — Defines a data cell.
- "<thead>" — Groups header rows.
- "<tbody>" — Groups the main data.
- "<tfoot>" — Groups summary rows.

🔹 8. Table Example

<table border="1">
    <caption>Student Marks</caption>
    <thead>
        <tr>
            <th>Name</th>
            <th>Subject</th>
            <th>Marks</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Shravan</td>
            <td>HTML</td>
            <td>90</td>
        </tr>
    </tbody>
</table>

🔹 9. colspan and rowspan

- "colspan" makes a cell span multiple columns.
- "rowspan" makes a cell span multiple rows.

These attributes are useful when combining table cells.

🧠 11. Interview Questions

Q1. What is the difference between "<ul>" and "<ol>"?

"<ul>" displays bullets, while "<ol>" displays items in an ordered sequence.

Q2. What is the purpose of "<li>"?

It represents a list item.

Q3. What is the difference between "<th>" and "<td>"?

"<th>" defines a header cell, while "<td>" defines a regular data cell.

Q4. What does "<tr>" mean?

It represents a table row.

Q5. What is a nested list?

A list placed inside another list.

Q6. What is the difference between "colspan" and "rowspan"?

"colspan" spans columns; "rowspan" spans rows.

Q7. Why do we use "<caption>"?

To provide a title or description for a table.
