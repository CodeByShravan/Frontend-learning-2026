📚 1. What is HTML?

HTML = HyperText Markup Language

HTML is a markup language used to create the structure of web pages.

HTML tells the browser what different parts of a webpage are.

For example:

- Heading
- Paragraph
- Image
- Link
- Button
- Form
- List
- Table

Simple definition

«HTML is used to create the structure of a webpage.»

---

❓ 2. Is HTML a Programming Language?

No.

HTML is a markup language, not a programming language.

HTML creates the structure of a webpage.

Programming languages such as JavaScript are used to add logic and functionality.

Example

HTML → Structure

CSS → Design

JavaScript → Logic/Functionality

Remember:

HTML       → Structure
CSS        → Styling
JavaScript → Behaviour

---

🌐 3. How a Website Works

A simple website can be understood like this:

HTML
  ↓
Structure

CSS
  ↓
Design

JavaScript
  ↓
Functionality

Example:

HTML → Creates a button
CSS → Makes the button beautiful
JavaScript → Makes the button perform an action

🏗️ 4. Basic HTML Structure

Every basic HTML document follows a structure like this:

<!DOCTYPE html>

<html lang="en">

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>This is my first webpage.</p>

</body>

</html>

---

🔍 5. Understanding the HTML Structure

"<!DOCTYPE html>"

This tells the browser that the document uses HTML5.

It is normally written at the beginning of an HTML document.

---

"<html>"

This is the root element of the HTML document.

All other HTML content is placed inside it.

Example:

<html>
    ...
</html>

---

"lang="en""

This tells the browser that the primary language of the document is English.

<html lang="en">

For Hindi content, you may use:

<html lang="hi">

---

🧠 6. "<head>"

The "<head>" contains information and settings about the webpage.

Example:

<head>
    <title>My Website</title>
</head>

Some common things placed inside "<head>" are:

- Title
- Character encoding
- Viewport information
- CSS links
- Metadata

---

🏷️ 7. "<title>"

The "<title>" defines the title of the webpage shown in the browser tab.

Example:

<title>My First Website</title>

---

👀 8. "<body>"

The "<body>" contains the content that appears on the webpage.

Example:

<body>

    <h1>Hello</h1>

    <p>Welcome to my website.</p>

</body>

---

📝 9. HTML Tags

HTML uses tags to describe different types of content.

Example:

<h1>Hello</h1>

Here:

<h1>      → Opening tag
Hello     → Content
</h1>     → Closing tag

Together they form an HTML element.

---

🧩 10. HTML Element

An HTML element generally consists of:

Opening Tag
     +
Content
     +
Closing Tag

Example:

<p>Hello World</p>

Here:

<p>           → Opening tag
Hello World   → Content
</p>          → Closing tag

---

⚠️ 11. Some Tags Do Not Have Closing Tags

Some HTML elements are called void elements.

Example:

<img src="photo.jpg" alt="My Photo">

There is no:

</img>

Other common examples include:

<br>
<hr>
<input>
<meta>
<link>

---

🔤 12. Headings

HTML provides six heading levels.

<h1>Main Heading</h1>

<h2>Heading 2</h2>

<h3>Heading 3</h3>

<h4>Heading 4</h4>

<h5>Heading 5</h5>

<h6>Heading 6</h6>

Important

"<h1>" is generally the most important/main heading.

"<h6>" is the least important heading level.

Example:

h1 → Main heading
h2 → Section heading
h3 → Sub-section
h4 → Smaller heading
h5 → Smaller heading
h6 → Smallest heading

---

📄 13. Paragraph

The "<p>" tag is used for paragraphs.

Example:

<p>
    I am learning Web Development.
</p>

---

💬 14. HTML Comments

Comments are notes written inside HTML code that are not displayed on the webpage.

Syntax:

<!-- This is a comment -->

Example:

<!-- Main heading -->
<h1>Hello Shravan</h1>

Comments are useful for explaining code.

---

📱 15. Viewport Meta Tag

This line is commonly used for responsive websites:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

It helps the webpage display properly on different screen sizes such as:

- Mobile
- Tablet
- Laptop
- Desktop

---

🔤 16. Character Encoding

We commonly use:

<meta charset="UTF-8">

UTF-8 supports a large range of characters and languages.

🎤 20. Interview Questions

Q1. What is HTML?

Answer:

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

---

Q2. Is HTML a programming language?

Answer:

No. HTML is a markup language, not a programming language.

---

Q3. What is HTML5?

Answer:

HTML5 is the modern version of HTML that provides many features for creating modern web pages and web applications.

---

Q4. What is the purpose of "<!DOCTYPE html>"?

Answer:

It tells the browser that the document is an HTML5 document.

---

Q5. What is the "<head>" element?

Answer:

The "<head>" contains information and settings about the HTML document, such as the title and metadata.

---

Q6. What is the "<body>" element?

Answer:

The "<body>" contains the content that is displayed on the webpage.

---

Q7. What is an HTML element?

Answer:

An HTML element generally consists of an opening tag, content, and a closing tag.

Example:

<p>Hello</p>

---

Q8. What is the difference between a tag and an element?

Answer:

A tag is the markup such as "<p>" or "</p>". An element includes the tags and the content between them.

Example:

<p>Hello</p>

The complete line is an element.
